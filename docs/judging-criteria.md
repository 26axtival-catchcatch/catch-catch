# 심사 기준

이 프로젝트가 제출되는 해커톤의 평가 항목과 배점입니다. 기획·화면 설계·데모 구성은
이 배점을 기준으로 판단합니다.

| 항목 | 배점 | 심사 내용 |
| --- | ---: | --- |
| 문제 정의 / 독창성 | 25 | 풀고자 하는 업무 문제가 명확하고, 접근이 새로운가 |
| Agent 설계 / 자율성 | 15 | Agent 구조가 합리적이고, 스스로 판단·수행하는 수준이 충분한가 |
| **완성도 / 신뢰성** | **30** | 실제로 동작하며, 결과가 일관되고 믿을 수 있는가 |
| 업무 효과성 / 확장성 | 20 | 업무 생산성에 실질적 효과가 있고, 다른 조직으로 확장 가능한가 |
| 발표 / 전달력 | 10 | 핵심이 잘 전달되고, 데모·설명이 설득력 있는가 |

합계 100점.

## 배점에서 나오는 판단 기준

가장 큰 항목이 **완성도 / 신뢰성 30점**입니다. "멋있는가"가 아니라 "믿을 수 있는가"를
묻습니다. 연출 중심의 화면은 오히려 "목업 아닌가"라는 의심을 부르므로, 다음 자산을
화면 앞으로 끌어올리는 쪽이 배점에 맞습니다.

- `LedgerClaim.verdict` — 검증 통과/탈락. **탈락한 주장도 그대로 노출**
- `TraceScore` — `claimsPassed / claimsTotal`, `evidenceCoverage`
- `EvidencePanel` — 마스킹된 증거 원문까지 이어지는 사슬
- 예측 → 관찰 → 채점(적중/빗나감) 루프. 빗나간 예측도 지우지 않음

`문제 정의 / 독창성 25점`에 대응하는 이 서비스의 주장은 "물어보면 답하는 도구"가 아니라
**"고객이 말하기 전에 잡고, 무엇이 달라질지 예측하고, 맞았는지 채점한다"** 입니다.
