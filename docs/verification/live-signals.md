## 남은 제한사항

Bedrock Run `09a29d35-aedf-46be-a736-632a0507f2c8`은 총괄과 세 조사를 완료했지만
독립 검증 모델 응답이 끝나지 않았습니다. 총 1039.41초 후 환경 재시작을 위해 검증용 Run을 수동 중단했습니다.
복원 상태는 `failed`, 공개 코드는 `run_cancelled`입니다. 성공한 실행으로 집계하지 않았습니다.
중단 직전 관측된 모델 호출은 47회이며, 조사 SQL은 75건입니다. 원인은 이번 핵심 구현 범위에서 확정하지 않았습니다.
애플리케이션의 시간·호출 제한을 다시 넣지 않았고 기본 Bedrock 설정도 변경하지 않았습니다.
현재 완료된 시연 증거를 재현하려면 `mode=gemini`를 명시합니다.

추가 scalar 지표의 SQL DECIMAL 출력은 현재 데이터 도구가 문자열로 직렬화하므로 측정 불가로 처리할 수 있습니다.
이 경우 `CAST(... AS DOUBLE)`을 사용합니다. 일반 COUNT와 DOUBLE 기반 SUM/AVG는 지원합니다.
정기 스케줄·자동 리포트·추이 화면·정의 편집은 후속 범위입니다.
